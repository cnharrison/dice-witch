# Quick start

Use `/roll` in Discord or open the [web Roller](/app).

## Roll in Discord

1. Type `/roll` in a channel where Dice Witch can respond.
2. Enter **notation**, such as `2d6+3`.
3. Optionally add a **title** or set **times** from 1 to 50.
4. Submit the command.

If `/roll` is missing, see [Troubleshooting](/docs/troubleshooting#discord-does-not-offer-roll).

## Roll from the website

1. Open the [Roller](/app) and sign in with Discord.
2. Choose a server and channel.
3. Enter notation, an optional title, and **Times**.
4. Select **Roll** to send the result to Discord.

The Roller only shows destinations where you and Dice Witch can complete the roll.

## Try these rolls

| Goal | Notation | Result |
| --- | --- | --- |
| Ability check | `1d20+5` | Roll a d20 and add 5. |
| Advantage | `2d20k1+5` | Roll two d20s, keep the highest, and add 5. |
| Damage | `2d6+3` | Roll two d6s and add 3. |
| Percentile | `d%` | Roll from 1 to 100. |
| Fate or Fudge | `4dF` | Roll four minus, blank, or plus dice. |

See [Dice notation](/docs/dice-notation) for arithmetic, groups, and modifiers. Use [Saved rolls](/docs/saved-rolls) for rolls you need often.
