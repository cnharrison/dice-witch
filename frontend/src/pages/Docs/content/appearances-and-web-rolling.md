# Appearances and web rolling

## Personal appearances

Open [Preferences](/app/preferences) and choose **Personal appearance**.

1. Select **All dice** or a specific die type.
2. Choose a preset or customize the colors, material, pattern, and typeface.
3. Save and apply the design.

A die-specific design overrides **All dice**. Clear that override to inherit **All dice** again.

## Server appearances

Administrators and Dice Witch Admins can configure **Server appearance** in [Preferences](/app/preferences).

| Mode | Behavior |
| --- | --- |
| **Off** | Members use their personal designs. |
| **Default** | A personal design wins; the server design fills anything not customized. |
| **Enforced** | The server design overrides personal designs for configured dice. |

Server designs can configure **All dice** and individual die types.

### Dice Witch Admin role

A server can create a role named exactly **Dice Witch Admin**. Members with that role can manage the Server Library, Server appearance, and roll-delivery preference without receiving Discord's Administrator permission.

## Roll delay

By default, Dice Witch posts a clatter message and waits for a brief random delay of up to five seconds before revealing the result. The pause is designed to recreate the anticipation of rolling dice in real life.

Administrators and Dice Witch Admins can turn it off for their server in [Preferences](/app/preferences) with **Skip dice roll delay and clatter message**.

## Roll from the website

1. Open the [Roller](/app).
2. Choose a Discord server and channel.
3. Enter notation, an optional title, and **Times**.
4. Select **Roll**.

Only destinations where you and Dice Witch can complete the roll are shown.

The Roller also includes Personal and Server [saved rolls](/docs/saved-rolls), plus up to three **Recent** rolls stored in this browser.

## Choose 2D or 3D dice

Use **Show 2D dice** or **Show 3D dice** in the result area.

- 2D is the image delivered to Discord.
- 3D is a fancy rendered view with physics, for funsies.
- Mobile and desktop remember their choices separately.
- If 3D is unavailable, use the 2D result.
