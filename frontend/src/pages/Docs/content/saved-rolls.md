# Saved rolls

Save rolls you use often, then load or send them without rebuilding the notation.

## Save a roll

From the [Roller](/app):

1. Choose a destination and enter the notation, optional title, and **Times**.
2. Select **Save**.
3. Enter a unique name, choose a library, and optionally choose a name color.
4. Select **Save** again.

From the [library manager](/app/library):

1. Open the personal library or a server library you manage.
2. Select **Create**.
3. Enter the name, notation, optional title, repetitions, and name color.
4. Select **Save**.

Both workflows save the notation, title, and repetition count.

## Personal and server libraries

| Library | Who can use it | Who can manage it | Limit |
| --- | --- | --- | --- |
| **Personal** | You | You | 50 rolls |
| **Server** | Current server members | Administrators and Dice Witch Admins | 100 rolls |

Server library access follows your current Discord membership. Using a server roll and managing the server library are separate permissions. See the [Dice Witch Admin role](/docs/appearances-and-web-rolling#dice-witch-admin-role).

## Use a saved roll on the website

Open **Library** in the Roller, then choose **Personal** or **Server**.

- Select a roll's name to load it into the Roller. You can change it before rolling.
- Select the dice button beside a roll to send it immediately to the chosen channel.
- Use search to filter the current library.

The Server tab appears only when the selected server has rolls you can use.

## Use a saved roll in Discord

Use `/library` in Discord to open a private picker.

1. Choose **Personal** or **Server**.
2. Move between pages when needed.
3. Select a roll.

The result is delivered where you used the command. For faster access, enter the optional **name** field and choose a roll from autocomplete.

## Manage your libraries

Open the [library manager](/app/library) to:

- create or edit a roll's name, color, notation, title, and repetitions;
- search by name, notation, title, or server;
- drag rolls into the order used by the web Roller and Discord;
- copy one roll between personal and server libraries;
- select one or more rolls from the same library and delete them.

Only authorized server managers can open and change a server library in the library manager.
